# Personal Portfolio Site Builder

A reusable AI agent skill for planning and building personal UI/UX portfolio websites. It helps beginners and designers create a clear portfolio structure, reusable project case studies, and named motion recipes they can request in prompts.

## What's included

- `portfolio-site-builder/SKILL.md` — the skill entry point, workflow, and design principles.
- `portfolio-site-builder/references/page-patterns.md` — reusable structures for the home page, project listing, case studies, about page, and contact page.
- `portfolio-site-builder/references/motion-catalog.md` — named motion recipes, their behavior, use cases, and implementation notes.
- `portfolio-site-builder/references/color-themes.md` — the original portfolio theme and a four-color blue, dark blue, green, and light blue palette, with suggested roles.

Page structure and visual themes are independent. Use the original theme, choose the four-color palette, or provide your own colors without changing the site structure.

## Installation and use

GitHub hosts and distributes the files; it does not automatically load the skill into each visitor's AI agent. Install the entire `portfolio-site-builder` folder using the skill directory or import feature supported by your agent.

1. Download or clone this repository.
2. Locate the `portfolio-site-builder` folder.
3. Copy the entire folder into the Skills directory specified by your agent, or use its supported skill import feature.
4. Start a task and describe the portfolio website you want to create. For example: “Use portfolio-site-builder to help me build a personal portfolio website.” You can request a motion by name, such as “Apply Staggered Reveal to the project cards.”

Installation locations and skill format support vary between agents. Follow your agent's official instructions. Install the whole folder, not just `SKILL.md`, so the page, motion, and color references are available too.

## What this skill helps with

Use it to plan or build a personal portfolio, reuse page sections, organize project case studies, and choose or implement named motion. The skill provides structure and guidance; users still need to supply their own biography, project content, images, and outcomes.

## Source and reuse

The page and motion patterns were distilled from the author's portfolio source files. This skill captures reusable structures and behaviors; it does not include the original site's personal copy, project assets, or source code. Use your own content and choose a visual style that fits your needs.
